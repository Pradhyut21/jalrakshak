Show the data label throughout. Use UI dates as the simulated clock, not the current real clock. Do not narrate physical repair, measured water savings, cloud deployment, model calls or human receipt that were not observed. The screenshots in artifacts/screenshots document browser checks; they are not an edited video or a real-site pilot.
